最初に1回だけ、WordPress側の設定が必要です。

CocoonのSEO欄(SEOタイトル・メタディスクリプション・メタキーワード)は、標準ではAPIから読み書きできません。 以下のコードスニペットを追加すると、このツールから未入力の記事を探して自動で書き込めるようになります。 記事の本文・URL・公開状態には影響しません。

  1. WordPress管理画面 →「プラグイン」→「新規追加」で Code Snippets を検索してインストール・有効化
  2. 「スニペット」→「新規追加」を開き、タイトルを「Cocoon SEO欄のAPI公開」などにする
  3. 下のコードを貼り付け、実行場所は「どこでも実行(Run snippet everywhere)」のまま「変更を保存して有効化」
  4. このページを再読み込み
add_action( 'init', function () {
    $keys = array( 'the_page_seo_title', 'the_page_meta_description', 'the_page_meta_keywords' );
    foreach ( $keys as $key ) {
        register_post_meta( 'post', $key, array(
            'type'          => 'string',
            'single'        => true,
            'show_in_rest'  => true,
            'auth_callback' => function () {
                return current_user_can( 'edit_posts' );
            },
        ) );
    }
} );

※ 「<?php」の行は不要です(Code Snippetsが自動で付けます)。元に戻したいときはスニペットを無効化するだけでOKです。
